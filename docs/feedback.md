# 동료 평가 반영 체크리스트

동료 평가 20개 항목(FAIL 2 · PASS 18)의 부족한 점과 보완 요청을 하나씩 반영한 기록입니다.
새 실측은 모두 같은 바이너리(`bin/agent-leak-app-x86`, sha256 `7e0a19cf…bb3e40`)를 [재현 컨테이너](../repro/Dockerfile)(Ubuntu 24.04 · 2 vCPU · 8GB · swap 없음)에서 2026-11-10 에 실행한 결과이고, 원본은 [`evidence/followup/`](../evidence/followup/) 에 있습니다(46회).
